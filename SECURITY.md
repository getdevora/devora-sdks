# Security policy

Report suspected vulnerabilities privately to hello@devora.sh. Do not disclose credentials or exploit details in a public issue. Include the affected package and version, reproduction steps and potential impact.

The current release line is 0.1.x: every `@devorash/*` npm package and `devora-*` PyPI package is released together at the same version. Migration notices are recorded in [CHANGELOG.md](./CHANGELOG.md). Repository source is not evidence that a registry release has completed.
